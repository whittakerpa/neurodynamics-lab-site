# neurodynamics-lab-site

Holding page for Neurodynamics Lab (neurodynamics.sg). Static HTML on Vercel, no build step.

- `index.html`: the page
- `vercel.json`: clean URLs and basic security headers

Vercel: import this repo as its own project (framework preset "Other"), then add neurodynamics.sg under Settings → Domains (A record `@` → the address Vercel shows).
